C.A.P

Modpack



Crash Warning!


There is currently a problem with the modpack caused by the 3 Furniture mods. The specific issue is that the game will crash upon skinning an entity and/or looting a corpse. This completely flew under my radar until recently, and I already fixed the problem in my personal install, which will become public soon, but until then, just disable or remove every Furniture and/or Hideout mod. Use MO2's VFS search feature to locate any scripts associated with the aforementioned mods that may be left behind as well. This should resolve the issue until I push out an official patch release.


Alternatively, you will have to disable FDDA (not recommended) if you want to keep the furniture mods, as that is where the script conflict is happening.

Project Description:


Short for "Corn's Anomaly Plus," this is a relatively light-weight modpack for S.T.A.L.K.E.R.: Anomaly, which aims to enhance the default experience of Anomaly without compromising on the stability of the same.


Keep in mind that you will need the base S.T.A.L.K.E.R.: Anomaly (duh), Modded EXEs / DLTX, and Mod Organizer 2. If you don't know how to get them up and running, I have a very useful guide covering that topic! Feel free to go and read said article, get all of those set up and running, and then come back here to proceed with the modpack installation.


File Size: ~10 GB (unzipped) + ~16 GB (base Anomaly)


How to install:


  1. Download the ZIP using the "Download File(s)" button from above.
  2. Open up your Mod Organizer 2 and create a new instance for my modpack.
  3. Open the Instance Manager button (usually in the top left corner).
  4. Select your C.A.P instance from the list, find the "Location" entry, and press "Explore."
  5. Now open the ZIP in one window and the Explorer (with your Instance folder loaded) in another. Open the "profiles" folder in your Explorer and copy the "Default" folder (entire folder; NOT just the contents of it) from the ZIP into the "profiles" folder. Now, go back and open the "mods" folder in the Explorer, and copy the entire contents of the "Mods" folder from the ZIP into that "mods" folder in the Explorer.
  6. Refresh your Mod Organizer 2, and the instance should now load with a modular list of all the add-ons that are present. If refreshing doesn't work, click the "Configure Profiles" button and make sure that "Default" is selected.
  7. Run the game and enjoy! :D

If you're a little confused on the whole process, I either already have or will make a video tutorial on my YouTube channel soon, so go watch that. If it already exists, a link to it can be found under the "Project Media" section.
